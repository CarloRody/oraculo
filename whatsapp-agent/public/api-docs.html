📱 API de WhatsApp

Envio automatizado de mensagens WhatsApp via API, com cobrança por mensagem descontada do seu saldo. Veja também o painel de administração.

Autenticação

Todas as chamadas usam a mesma chave de acesso já utilizada nas demais APIs do Oráculo (ex: /api/chat), enviada no cabeçalho:

X-Oraculo-Key: SUA_CHAVE_DE_ACESSO

Sua chave de acesso é fornecida pelo administrador do Oráculo. Cada requisição é identificada e cobrada na conta dessa chave.

Base URL: este endpoint fica no serviço principal do Oráculo (não no serviço de WhatsApp) — use o mesmo endereço que você já usa pra /api/chat, por exemplo https://SEU-DOMINIO-ORACULO.

Enviar mensagem

POST/api/whatsapp/send

Envia uma mensagem de texto e/ou até 10 arquivos anexados pelo número de WhatsApp vinculado à área informada. A conexão usada é resolvida automaticamente a partir do vínculo área ↔ conexão configurado no seu cadastro (feito pelo administrador). Cada mensagem enviada com sucesso é cobrada e descontada do seu saldo, conforme o preço configurado no seu plano para essa área — inclusive cada arquivo anexado, ver Anexando arquivos abaixo.

Parâmetros do corpo (JSON)

CampoTipoObrigatórioDescrição
area_idintegerSimID da área vinculada à conexão que vai enviar a mensagem
phonestringSimNúmero de destino, só dígitos, com código do país (ex: 5511999999999)
messagestringSim, a menos que files tenha pelo menos 1 itemTexto da mensagem. Se enviado junto com files, vira a legenda de cada arquivo anexado
filesarraySim, a menos que message venha preenchidoLista de arquivos a anexar (máximo 10) — ver Anexando arquivos

Exemplo de requisição (texto)

POST /api/whatsapp/send HTTP/1.1
Host: SEU-DOMINIO-ORACULO
X-Oraculo-Key: SUA_CHAVE_DE_ACESSO
Content-Type: application/json

{
  "area_id": 3,
  "phone": "5511999999999",
  "message": "Olá! Seu pedido foi confirmado."
}

Anexando arquivos

Cada item de files vira uma mensagem separada no WhatsApp — a plataforma não permite mais de um anexo por mensagem. Os arquivos são enviados em sequência, na ordem da lista, todos pra mesma conversa. Se message também for enviado, o mesmo texto aparece como legenda em cada arquivo.

Campos de cada item de files

CampoTipoObrigatórioDescrição
filestringSimConteúdo do arquivo em base64 (sem o prefixo data:...;base64,, só o conteúdo)
file_namestringSimNome do arquivo como deve aparecer pra quem recebe (ex: exame.pdf)
mime_typestringSimTipo MIME do arquivo — ver tipos aceitos abaixo

Tipos aceitos e limites

Tipomime_type
PDFapplication/pdf
Imagem JPEGimage/jpeg
Imagem PNGimage/png
Imagem WebPimage/webp
XMLapplication/xml ou text/xml
Word (.docx)application/vnd.openxmlformats-officedocument.wordprocessingml.document
Excel (.xlsx)application/vnd.openxmlformats-officedocument.spreadsheetml.sheet

Tamanho máximo de 10MB por arquivo (antes da conversão pra base64) e no máximo 10 arquivos por chamada. Se qualquer arquivo da lista tiver tipo não permitido, tamanho acima do limite ou base64 inválido, a chamada inteira é rejeitada com 400 antes de mandar qualquer coisa — nunca envia nem cobra parte da lista nesse caso.

Exemplo de requisição (com anexo)

POST /api/whatsapp/send HTTP/1.1
Host: SEU-DOMINIO-ORACULO
X-Oraculo-Key: SUA_CHAVE_DE_ACESSO
Content-Type: application/json

{
  "area_id": 3,
  "phone": "5511999999999",
  "message": "Segue o resultado do seu exame.",
  "files": [
    {
      "file": "JVBERi0xLjQKJ...",
      "file_name": "exame.pdf",
      "mime_type": "application/pdf"
    }
  ]
}

Resposta de sucesso 200 OK

{
  "ok": true,
  "status": "sent",
  "chat_id": 42,
  "sent_count": 1,
  "charged_count": 1,
  "credit_status": {
    "balance": 123.4500,
    "depleted": false
  }
}
CampoDescrição
status"sent" quando tudo foi enviado; "partial" quando files tinha mais de 1 item e algum deles falhou no meio (os anteriores já foram enviados e cobrados, ver warning). Não há confirmação de entrega/leitura nesta versão da API.
chat_idID interno da conversa, útil se você quiser consultar o histórico depois
sent_countQuantas mensagens de fato saíram (1 se só texto; 1 por arquivo em files)
charged_countQuantas dessas mensagens foram cobradas — normalmente igual a sent_count, só é menor se o saldo zerou no meio do envio (mensagens já enviadas não deixam de ser cobradas por engano, mas também não é cobrado além do que existe de saldo)
warningSó aparece quando status é "partial" — descreve o que impediu os arquivos restantes de serem enviados
credit_status.balanceSeu saldo em R$ após os débitos desta chamada
credit_status.depletedtrue quando o saldo chegou a zero ou menos após esta chamada

Respostas de erro

CódigoSituação
400Parâmetro obrigatório faltando, área não disponível para sua chave, nenhuma conexão WhatsApp vinculada a essa área, ou algum item de files inválido (tipo não permitido, maior que 10MB, base64 inválido, ou mais de 10 arquivos)
401Chave de acesso ausente ou inválida
402Seus créditos acabaram
403Conta desativada, ou envio de mensagens não configurado (sem preço definido) para essa área — fale com o administrador
502Falha ao enviar — conexão WhatsApp indisponível no momento. Nada foi cobrado.

Toda resposta de erro segue o formato:

{ "error": "descrição legível do problema" }

Exemplo de uso em PHP

Usa apenas cURL, sem dependências externas:

<?php

$apiKey  = 'SUA_CHAVE_DE_ACESSO';
$baseUrl = 'https://SEU-DOMINIO-ORACULO';

/**
 * Envia uma mensagem de WhatsApp via API do Oráculo.
 * Lança RuntimeException em caso de falha (rede ou erro retornado pela API).
 */
function enviarMensagemWhatsapp(string $baseUrl, string $apiKey, int $areaId, string $telefone, string $mensagem): array
{
    $payload = json_encode([
        'area_id' => $areaId,
        'phone'   => $telefone,
        'message' => $mensagem,
    ]);

    $ch = curl_init(rtrim($baseUrl, '/') . '/api/whatsapp/send');
    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_POST           => true,
        CURLOPT_POSTFIELDS     => $payload,
        CURLOPT_HTTPHEADER     => [
            'Content-Type: application/json',
            'X-Oraculo-Key: ' . $apiKey,
        ],
        CURLOPT_TIMEOUT        => 30,
    ]);

    $responseBody = curl_exec($ch);
    $httpCode     = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $curlError    = curl_error($ch);
    curl_close($ch);

    if ($curlError) {
        throw new RuntimeException("Erro de conexão: {$curlError}");
    }

    $data = json_decode($responseBody, true);

    if ($httpCode !== 200) {
        $erro = $data['error'] ?? 'Erro desconhecido';
        throw new RuntimeException("Falha ao enviar mensagem ({$httpCode}): {$erro}");
    }

    return $data;
}

// Uso:
try {
    $resultado = enviarMensagemWhatsapp(
        $baseUrl,
        $apiKey,
        3,                      // area_id
        '5511999999999',       // telefone (DDI + DDD + número, só dígitos)
        'Olá! Seu pedido foi confirmado.'
    );

    echo "Mensagem enviada com sucesso. chat_id: {$resultado['chat_id']}\n";

    if (!empty($resultado['credit_status'])) {
        $saldo = number_format($resultado['credit_status']['balance'], 2, ',', '.');
        echo "Saldo restante: R$ {$saldo}\n";

        if ($resultado['credit_status']['depleted']) {
            echo "Atenção: seus créditos acabaram — recarregue para continuar enviando.\n";
        }
    }
} catch (RuntimeException $e) {
    echo "Erro ao enviar mensagem: " . $e->getMessage() . "\n";
}

Exemplo com anexo (PHP)

Mesma função acima, só muda o payload — adiciona um item em files com o conteúdo do arquivo em base64:

$caminhoArquivo = '/caminho/para/exame.pdf';

$payload = json_encode([
    'area_id' => 3,
    'phone'   => '5511999999999',
    'message' => 'Segue o resultado do seu exame.',
    'files'   => [
        [
            'file'      => base64_encode(file_get_contents($caminhoArquivo)),
            'file_name' => basename($caminhoArquivo),
            'mime_type' => 'application/pdf',
        ],
    ],
]);

// O resto da chamada (curl_init, headers, etc.) é igual ao exemplo anterior —
// só troca o $payload por esse.
Cada mensagem enviada com sucesso é cobrada conforme o preço por mensagem configurado para a área usada — inclusive cada arquivo anexado conta como uma mensagem própria. Se você receber erro 403 dizendo que o envio não está configurado, ou 402 de créditos esgotados, entre em contato com o administrador do Oráculo.
